# Student Performance Classification using Neural Network

A simple **Neural Network built from scratch using NumPy** to predict whether a student will **Pass or Fail** based on study-related features.

## What I Used

* **Python & NumPy** – For data handling and neural network calculations
* **Dense Layers** – Hidden layer with 4 neurons and an output layer with 1 neuron
* **ReLU Activation** – Introduces non-linearity in the hidden layer
* **Sigmoid Activation** – Converts the output into a pass probability
* **Binary Cross-Entropy** – Calculates the classification loss
* **Backpropagation** – Calculates gradients from the error
* **Gradient Descent** – Updates weights and biases to reduce the loss
* **Epochs & Learning Rate** – Control the training process

## How It Works

```text
Input Data
    ↓
Dense Layer
    ↓
ReLU
    ↓
Dense Layer
    ↓
Sigmoid
    ↓
Prediction
    ↓
Loss Calculation
    ↓
Backpropagation
    ↓
Gradient Descent
    ↓
Weight Update
    ↓
Repeat
```
